# 🎮 RPS Arena — Rock Paper Scissors

A modern, arcade-themed **Rock Paper Scissors** web game featuring a glassmorphic UI, animated battle countdowns, synthesized Web Audio sound effects, and multiple match modes.

## ✨ Features

- **Glassmorphic Arcade Interface**: Responsive dark-mode design built with Tailwind CSS and custom frosted-glass panels.
- **Animated Battle Stage**: Synchronized 3-step countdown (`ROCK... PAPER... SCISSORS!`) with fist-shaking animations and win/loss glow indicators.
- **Built-in Web Audio Synthesizer**: Zero external audio files required—generates crisp sound effects for ticks, wins, losses, and ties with a mute toggle.
- **Multiple Game Modes**: Switch between **Endless**, **Best of 3**, and **Best of 5** matches.
- **Stats & Round History**: Tracks player vs. CPU score, ties, active win streaks, and recent round matchups.
- **Keyboard Shortcuts**: Play rapidly using `R` (Rock), `P` (Paper), and `S` (Scissors).

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3 & Tailwind CSS (CDN)** — Glassmorphism, custom keyframe animations, and responsive grid layout
- **Vanilla JavaScript (ES6+)** — Game state management, animations, and Web Audio API synthesis
